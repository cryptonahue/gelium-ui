## Tweet 2 — Qué es

Gelium UI es open-code: copias HTML semántico y lo estilas con tokens CSS (--ui-*).

Sin runtime cliente. Sin hidratación. Sin CDN.

Pensada para Tailwind CSS 4. HTMX si lo quieres, nunca como requisito.

Media: captura de una página de componente (p. ej. /components/button) mostrando el parcial HTML.

---

## Tweet 3 — El contrato 0-JS

El contrato 0-JS es la columna vertebral:

• Los botones son <button>, los diálogos son <dialog>
• El flujo principal se completa con JS deshabilitado
• JS es solo mejora progresiva (~5KB opcionales)

Tu UI sobrevive aunque los scripts fallen o tarden.

Media: GIF/video corto deshabilitando JS en el navegador y navegando el sitio igual.

## Tweet 4 — Temas

¿Te gusta la estética de shadcn?

Los 8 style packs de Basecoat (Vega, Nova, Mira, Lyra…) están traducidos token a token, con evidencia.

También: Material 3, Linear, Vercel, Alden.

Cambiar de tema = una clase en <html>. Sin rebuild. Sin tocar markup.

Media: captura de la galería de temas (/docs/themes/gallery) con varios temas side-by-side.

## Tweet 5 — Arquitectura

La arquitectura separa comportamiento, referencia visual y skin.

En la práctica: un mismo componente semántico se viste como Material, Basecoat o Linear sin bifurcar código.

Y la densidad respeta pisos de accesibilidad: touch target ≥44px siempre.

Media: mismo select con ?skin=basecoat-mira vs ?skin=basecoat-nova vs tema Material.
