# UI Vocabulary — description-to-name resolver

Agent-facing glossary: given an informal description of a UI element ("the dark
see-through layer behind a popup"), resolve it to a canonical name before naming
or building anything new.

Vocabulary source: namethatui.com (used with attribution; removal on request).

Usage: grep this file for keywords from the user's description. If a canonical
name exists, use it (component, class prefix, docs, commit messages). Check
`docs/gelium-ui-vocabulary.md` §8 for already-resolved naming conflicts before
creating any new component.

## Web vocabulary (alphabetical)

- **Accordion (Disclosure)** — Stacked sections whose headings expand and collapse their content. Also called: disclosure, expandable sections, collapse, expander, it has a plus icon when collapsed and minus icon when expanded, the list where rows open to show more, expand and collapse sections, the faq with clickable questions. API: `<summary>`, `<summary>::marker`, `<details>`.
- **Avatar Group** — Overlapping profile circles with a ring between them and a +N at the end. Also called: facepile, avatar stack, stacked avatars, grouped avatars, avatar pile, the overlapping circles of profile pictures, avatar list, lost of people. API: `margin-inline-start: -10px`, `border`, `AvatarFallback`, `AvatarGroupCount`.
- **Badge vs. Chip vs. Pill vs. Tag** — Compact labels distinguished by meaning, shape, and interactivity. Also called: token, lozenge, capsule, the little number bubble on an icon, the rounded label with an x, the capsule shaped status label, the small category label on a card, the removable filter bubble. API: `Badge`, `<button aria-label>`, `aria-pressed`.
- **Bento Grid** — One grid, mixed tile sizes — a layout packed like a bento box. Also called: bento box layout, feature grid, dashboard grid, several boxes in a grid bento, boxes of different sizes in a grid, the grid with one big box and smaller boxes around it, the apple style feature grid with rounded cards, dashboard made of different sized tiles. API: `grid-column: span 2`, `gap`, `display: grid + grid-column: span 2`, `grid-template-columns: repeat(4, 1fr)`.
- **Breadcrumbs** — A hierarchy trail from the current page back to its ancestors. Also called: breadcrumb trail, path navigation, hierarchy trail, the home slash section slash current page links, the trail above a page title, links showing where you are in the site, the folder path style navigation, the row with chevrons between page names. - **Card** — The rectangle with media, title, body, and a footer — every part has a name. Also called: tile, card component, content card, status card, status cards, score card, task card structure, those cards have a massive chin. Also called: slider, content slider, slideshow, image slider, swiper, a card slider, carousel slider thing, the image slider with the little dots. - **Combobox (Autocomplete / Typeahead)** — A text input paired with a filtered list of selectable suggestions. API: `role="combobox"`, `role="listbox"`, `aria-activedescendant`, `aria-selected`.

Also called: command menu, quick actions, launcher, command bar, the command k menu, the searchable list of app actions, the quick launcher in the middle of the screen, the keyboard popup for jumping anywhere. API: `CommandInput`, `CommandGroup`, `CommandItem`, `CommandShortcut`.

Also called: calendar picker, calendar popup, calendar dropdown, date range picker, month view, calendar, calendario, date range filter calendar. API: `button_previous / button_next`, `range_start / range_end`, `range_middle`, `today`.
- **Divider vs. Separator vs. Rule** — The same thin line can mark a topic break, separate controls, or be decoration. Also called: separator, rule, horizontal rule, visual divider, between those line breaks, above that line break, a vertical line break between those sections, the line break divider between the actual kind of title and the download button. API: `<hr>`, `role="separator"`, `border-block-start`, `Divider / NSMenuItem.separator()`.
- **Drag & Drop** — The grips, handles, previews, and landing cues around a drag interaction. Also called: drag and drop, drag-and-drop interaction, direct manipulation, sortable drag, those kind of a 3x3 or 2x2, those squares, you know, that are on the corners, line indicators for where it will drop, the neighboring terminal is highlighted as a whole. API: `draggable="true"`, `pointer events`, `ondragover`.
- **Easing (Timing Function)** — The speed curve of an animation — why motion feels smooth or robotic. Also called: timing function, easing curve, bezier curve, the animation feels robotic and linear, how the movement speeds up and slows down, the curve that controls the animation speed, make it start fast and end slow, the s shaped graph in the animation settings. API: `cubic-bezier(x1, y1, x2, y2)`, `transition-timing-function`, `cubic-bezier(.4, 0, .2, 1)`, `linear(…)`.
- **Empty State** — Purposeful guidance shown when a view has no content yet. Also called: blank state, zero state, first-use state, no-results state, the screen shown when there is nothing here, the panel before the user creates their first item, the no results message with a button, the blank list explanation. - **Focus Ring (:focus-visible)** — The keyboard-aware outline that identifies the active control. Also called: focus indicator, keyboard focus outline, focus halo, the outline around a button after pressing tab, the blue ring on the selected control, keyboard navigation highlight, the border showing which button has focus, the ring that should not appear on every mouse click. - **Form Field** — Every part of a labeled input — label, placeholder, helper text, and the red error line. Also called: text field, input field, form input, form control, the gray text inside the box that disappears when you type, the little red star next to the label, the small gray text under the input, the red error message under the field. Also called: hover preview, profile preview, preview card, the profile preview when you hover a username, the rich popup that appears over a link, the little user card shown on hover, a tooltip with an avatar and details, the preview before opening a profile. - **Inline Alert vs. Callout vs. Banner** — Three in-page notices named by where they sit, and none of them is a toast. Also called: inline alert, inline notification, callout, admonition, notice, warning box, announcement banner, notification banner. API: `border-inline-start`, `variant="standard"`, `severity="warning"`, `onClose`.
- **Lightbox** — The click-to-enlarge image overlay that dims the page behind it. Also called: image viewer overlay, photo modal, gallery overlay, when you click a photo and it opens big with a dark background, the enlarged image popup in a gallery, click the thumbnail and it zooms over the page, the image viewer with arrows for the next photo, the big photo over a black background. Also called: ticker, logo carousel, auto-scrolling strip, the logos that scroll sideways by themselves, the news ticker text, the endless scrolling logo strip, text that moves across the screen on its own, the auto sliding brand logos. - **Masonry Layout (Pinterest Grid)** — Cards of different heights packed into columns with no row gaps. Also called: waterfall layout, pinterest grid, brick layout, the pinterest style grid where every card is a different height, photos stacked like bricks with no gaps, columns where the cards don't line up in rows, the photo wall where images keep their own height, cards that fill in under each other instead of in rows. - **Modal Dialog vs. Drawer vs. Sheet** — Three overlay patterns distinguished by placement, scope, and task depth. Also called: modal, side panel, slide-over, bottom sheet, the popup in the middle that blocks the page, the panel that slides in from the side, the tray that comes up from the bottom, an overlay for editing without leaving the page. - **Multi-select** — One control holding several values: the checkbox dropdown, the chip field, and the two-pane transfer list. Also called: multiselect, multiple select, multi-select dropdown, checkbox dropdown, multi-select listbox, token multi-select, transfer list, pick list. API: `Select.ValueText`, `role="option" aria-selected="true"`, `TagsInput.Item / TagsInput.ItemDeleteTrigger`, `<Transfer dataSource targetKeys>`.
- **Pagination** — The numbered page buttons under a list — and the dot version, the page control. Also called: pager, paging controls, page navigation, page numbers, page control, datatable pagination, page number for tables, the numbered buttons at the bottom of the list. API: `aria-current="page"`, `<PaginationPrevious />`, `<PaginationEllipsis />`, `UIPageControl`.
- **Parallax Scrolling** — Layers that scroll at different speeds — the background lags and depth appears. Also called: parallax effect, parallax background, scroll-linked depth effect, fixed background, efecto de imagen atras de web, ful page paralax animation, paralax, the background moves slower than the page when you scroll. API: `translateZ(-1px) scale(2)`, `translateZ(0)`, `animation-timeline: scroll()`, `perspective + translateZ() + scale()`.
- **Popover vs. Dropdown Menu vs. Tooltip** — Three anchored overlays with different triggers, content, and dismissal rules. Also called: popup, menu, hover hint, toggletip, the little box attached to a button, the list that opens under a menu button, the label that appears when you hover, a popup with controls inside it. API: `popovertarget`, `role="menuitem"`, `Tooltip.Arrow`, `popover`.
- **Progress Ring vs. Spinner vs. Progress Bar** — A spinner means wait; a ring or bar can show how much work is complete. Also called: circular progress indicator, loading spinner, determinate progress indicator, linear progress indicator, that circle for the countdown, that circle that gets filled up, the actual circular progress bar, the menu bar like ring getting filled up, the ring that fills up. API: `role="progressbar"`, `aria-valuenow`, `<progress>`.
- **Resize Handle (Size Grip)** — The three diagonal lines in a text box's corner that you drag to make it bigger. Also called: size grip, resize grip, gripper, resizer, drag corner, three small diagonal lines at the bottom right of a text field, the corner thing you drag to make the text box bigger, the little diagonal stripes in the corner of a comment box. API: `::-webkit-resizer`, `resize`, `<textarea>`.

Also called: backdrop, overlay, modal overlay, the dark see-through layer behind a popup, the page dimming when a modal opens, the grey overlay behind a dialog, the layer that blocks clicks behind the panel, the faded background under a popup. Also called: spring physics, bouncy animation, spring transition, the bouncy animation that goes past and comes back, it overshoots a little and settles, the jelly bounce when a panel opens, ios style bouncy movement, animation with stiffness and damping instead of duration. Also called: stepper, wizard progress indicator, step indicator, step-by-step indicator, multi-step progress, step bar, the numbered circles showing step 1 2 3 at checkout, series of badges that indicate step. API: `Steps.Indicator`, `<StepConnector />`, `Steps.Status`, `aria-current="step"`.
- **Sticky vs. Fixed Positioning** — Two ways to keep an element visible with different containing blocks. - **Switch vs. Checkbox vs. Radio** — Controls for an on/off setting, independent choices, or one choice from a group. Also called: toggle switch, check box, radio button, option button, the on off sliding control, the square box with a checkmark, the circles where only one can be picked, a setting that changes immediately. API: `role="switch"`, `<input type="checkbox">`, `<input type="radio">`.
- **Tabs** — A single row of labels that switches one shared content region. Also called: tabbed interface, tab list, tab bar, the row of labels that switches the panel below, sections with an underline under the active one, clickable headings for changing views, the horizontal switcher above content, browser tab style navigation inside a page. - **Text Scramble (Decode Effect)** — Random characters churn and settle into the real text. Also called: decode effect, matrix text effect, shuffle text, the text that shuffles random letters until it spells the word, the matrix style decoding text, letters cycling before they land on the real ones, the hacker text effect, glitchy letters that resolve into a title. API: `chars (ScrambleTextPlugin)`, `ScrambleTextPlugin`, `requestAnimationFrame + charset swap`, `font-variant-numeric: tabular-nums`.
- **The Three Dots (Overflow Menu)** — Horizontal dots, vertical dots, three lines, and an ellipsis mean different things. Also called: kebab menu, meatball menu, hamburger menu, overflow menu, more menu, ellipsis button, the three dots menu, the horizontal meatballs button. API: `button[aria-haspopup="menu"]`, `button[aria-controls]`, `<button>Open…</button>`.

Also called: snackbar, status toast, in-app notification, the little message that pops up in the corner, confirmation that disappears by itself, saved successfully popup, temporary message after clicking a button, small alert at the bottom of the screen. - **Toggle Group (Segmented Control)** — A connected row of compact options with one persistent selection. - **Truncation (Ellipsis & Line Clamp)** — Text cut short with … — at the end of the line, after N lines, or in the middle. Also called: ellipsis, text overflow, line clamp, clamped text, truncated text, the text gets cut off with three dots, show only two lines then dot dot dot, long file name with dots in the middle.
