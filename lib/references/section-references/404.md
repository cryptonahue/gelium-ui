# REF-404

Source: https://vercel.com/docs/errors/does-not-exist
Kind: section · type: 404 · tags: error, recovery, not-found

## Structure

```text
clear not-found identity (one H1)
short explanation
one primary path back
optional secondary help
```

## Gelium adaptation

- Prefer `ui-error-state` (or product-equivalent) with one H1
- One canonical recovery link; secondary help is optional and quieter
- No screenshot-only error, no unrelated recipe body
- Force honest status semantics in the app layer (do not soft-200 a missing resource)

## Reject

Marketing hero as 404, multiple competing primaries, decorative dead-ends with no way out.
