# REF-ARTICLE

Source: https://vercel.com/blog/the-end-of-credential-sprawl-for-agents
Kind: section · type: article · tags: read, detail, prose, media

## Structure (reading order)

```text
article chrome (product shell out of scope)
H1
author · date · read-time
lead
optional hero media
H2/H3 sections with prose
code / evidence / tables
related content
optional marketing CTA (often reject on Read surfaces)
```

## Gelium adaptation

- `SURFACE=Read`, `SCREEN=detail`
- One H1; readable prose measure
- Native media with alt / captions / transcript when media is real product content
- Visible source / provenance when claims matter
- Loading / empty / error recovery owned by the page
- Rebuild structure with tokens — **do not** copy skin, logo, assets, or commercial claims
- A Read page does not require a marketing light/dark hero pair to start

## Reject

Copied brand, invented metrics, screenshot-only body, second primary CTA fighting the article.
