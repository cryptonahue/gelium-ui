# REF-SOCIAL-FEED

Origin: user-supplied responsive screenshots; visual evidence is development-only and lives outside this npm package.

Patterns: metadata → title/body → optional media/quoted content → actions; single-column narrow feed; constrained medium feed; compact shell; responsive media containment; action bar; empty/loading/error/recovery states.

Gelium filter: use the consumer's existing shell and real data. Do not copy social brand, avatars, metrics, composer, sidebars, bottom navigation, or external content. Resolve actions such as bookmark/like through the icon catalog while keeping accessible labels and server/no-JS contracts.
