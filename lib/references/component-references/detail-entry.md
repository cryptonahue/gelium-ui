# REF-CARD-DETAIL-ENTRY

Use when a list/card contains both navigation and mutation controls.

Pattern: make one reading region (title, context, summary, safe media) link to the canonical detail route; keep like/save/delete/forms outside that link. Remove duplicate `View` links when the reading region already provides the same destination.

Check nested interactive elements, keyboard focus, target size, GET/POST semantics, and the mobile reading order.
