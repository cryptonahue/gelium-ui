Gelium agent gates — proportional operational flow

Route small work directly; gate only architectural UI work. The ledger attests decisions and evidence, memory is advisory, and tooling can block a phase claim—not local typing or ordinary delivery.

Proportional routing

Small understood fixes follow the direct path. Architectural UI work follows Route → Orient → Plan → Architect → human approval; only then does one writer build the agreed shape.

Two evidence phases

Prebuild checks the intent, architecture packet, approval, and criteria plan. Postbuild checks rendered wide/narrow, themes, real states, no-JS, detector findings, and evidence limitations.

Bounded authority

Explorers are read-only and exact-path; one writer changes production; a fresh reviewer audits the candidate. Memory can guide Orient, but repository artifacts and human decisions remain authoritative.
