# Gelium UI — UX decision pack (for agents)

Machine-oriented rules. Human pages: /docs/screens /docs/feedback /docs/journeys /docs/data-display /docs/patterns /docs/density /docs/motion /docs/ui-definition-of-done
Obey Forms, Content style, Server contracts, Responsive. Stack: server HTML + gelium-ui CSS; JS optional.

## MUST before generating UI

1. SCREEN TYPE: hub | list | detail | form | confirm | settings | queue | result
2. USER JOB: one sentence
3. ONE PRIMARY ACTION
4. JOURNEY-* if multi-step; DATA-* if collection
5. STATES: loading | empty | error | success (+ FEED-*)
6. CONTROLS: choose-the-right-control + forms
7. SERVER: GET read; POST+303 mutate; 422+X-Gelium-Validation
8. THEME: theme-* on html
9. NARROW: stack; min-width:0; no overflow-x:hidden on body
10. Run UI DoD (/docs/ui-definition-of-done) before handoff

## SCREEN types → blocks

| Type | Blocks |
|---|---|
| hub | title, short context, one primary button |
| list | data-table OR list/card, filters, pagination, empty-state |
| detail | title, status badge, body, secondary actions |
| form | fields, validation-summary, primary+cancel |
| confirm | dialog/confirm route, destructive button, cancel |
| settings | list rows, switch/select |
| queue | list/table, badge, row POST actions |
| result | success banner/alert, next links, optional toast |

## JOURNEY shapes

| ID | Use |
|---|---|
| JOURNEY-START | hub + one CTA before work |
| JOURNEY-LINEAR | ordered steps; Continue; back to prior GET |
| JOURNEY-TASKLIST | long resumable multi-task (only if needed) |
| JOURNEY-BRANCH | server 303 to different next by answer |
| JOURNEY-CRUD | list ↔ detail ↔ form |
| JOURNEY-QUEUE | work item actions |

Landings: 422→same form (FEED-VAL); create→detail/list (FEED-OK-PAGE/TOAST); finish multi-step→result page not toast-only.

## DATA display

| ID | Use | Never |
|---|---|---|
| DATA-TABLE | compare many attrs / admin | layout/marketing |
| DATA-LIST | title + few meta + row action | 8-column numeric compare |
| DATA-CARDS | browse entities | dense reconciliation |
| DATA-FEED | time-ordered activity | master data admin |
| DATA-QUEUE | process work items | read-only catalog |
| DATA-DESC | one record fields | hundreds of peers |

Collections MUST implement FEED-LOAD-LIST, FEED-EMPTY, FEED-LOAD-FAIL (+ FEED-ROW/PARTIAL if actions).

## FEEDBACK matrix (abbrev)

| ID | Use | Never |
|---|---|---|
| FEED-VAL | summary+inline+422 | toast-only validation |
| FEED-OK-TOAST | brief success in-flow | sole success on blank page |
| FEED-OK-PAGE | success on result page | |
| FEED-FAIL | banner/alert+retry | vanishing toast if critical |
| FEED-EMPTY | empty-state+CTA | blank table |
| FEED-LOAD-LIST | skeleton in list | full-app block every refetch |
| FEED-ROW | error near row | toast-only row fail |
| FEED-PARTIAL | counts+per-item | green toast "Done" |
| FEED-CONFIRM | confirm+POST | toast-only delete |

Full FEED-* list: /docs/feedback

## NAV

| Need | Prefer |
|---|---|
| 1–3 section levels | side nav/drawer |
| 3–5 app peers mobile | nav bar |
| same object modes | tabs |
| long doc | on-this-page |
| depth≥2 | breadcrumb |
| <5 pages | simple top links |

## DENSITY

comfortable | cozy (default) | compact — one mode per surface; never shrink below --ui-touch-target.

## MOTION

MOTION-NONE default. Else FEEDBACK|STATE|NAV only. Honor prefers-reduced-motion. Token durations.

## DOMAIN SKELETONS

| ID | Shape |
|---|---|
| SKEL-FORUM | list topics → thread → reply form |
| SKEL-CATALOG | cards/list + detail + cart/checkout linear |
| SKEL-ADMIN-RESOURCE | recipe admin-resource |
| SKEL-OPS-QUEUE | recipe ops-queue |
| SKEL-SETTINGS | settings list + section forms |
| SKEL-ONBOARDING | start → steps → result |

## HIERARCHY

H1 → context → primary → main → secondary. F-pattern: don't bury sole CTA.

## COPY

Errors=fix first. Toasts=verb+result. Empty=what/why/next. Partial=counts+next.

## DoD (short)

Job, screen type, journey/data ids, one primary, FEED states, forms+server, theme, narrow, motion, content-style, skeleton if domain. Full: /docs/ui-definition-of-done
